# Agent-assisted review

Agent research, source qualification and repair are accepted parts of execution. Record what the agent did; never call assisted work unattended or prospective. Read `docs/agent_assisted_release.md` for the finite release contract and `docs/autoresearch_status.md` for current ownership and next work. Repository paths below are relative to its root. This skill is repository-local; invoke it by its path. It is not installed into global agent settings.

Before mutation, reconcile applicable AGENTS, Git changes, process IDs, launcher/exit receipts and unfinished submissions. Preserve other operators and original evidence. One scientific execution owner at a time. A stale status is not evidence that a process exited. Do not duplicate uncertain submissions.

## Select the workflow

Read [operating workflows](references/workflows.md), selecting only the needed branch:

- New review/benchmark: establish question, report-to-study inventory, outcome/time/arm semantics and supported statistical design before freeze. Reference answers are evaluator-only.
- Missing source: lawful bounded new route, receipt-backed import and explicit source upgrade. Preview/abstract access is not full text.
- Quote or layout failure: diagnose exact missing anchor; repair only evidence with fixed scientific values, then independently verify semantics. Do not relax literal gates or apply the binary image module to continuous data.
- Family or denominator uncertainty: collate reports without multiplying studies; distinguish planned/randomized/analyzed N and unresolved population bridges.
- Interrupted execution: use bounded receipt-classified continuation, not a blind rerun.
- Evaluation/release: audit existing artifacts into a new directory and report separate coverage, input, numerical and execution outcomes.

## Non-negotiable scientific stops

Stop admission of the affected input—not all independent work—when original evidence cannot establish outcome, unit, arm, timepoint, dispersion, analyzed N, allocation unit or family independence. Never substitute a review's values, infer balanced withdrawals, assume ICC/correlation, or treat a matching quote as proof of its statistical meaning. Positive overlap and integrity notices remain active constraints. A verified secondary report is still potentially valuable evidence; report role alone does not erase its missing full-text gap.

A changed estimand, cutoff, transformation, family policy or evidence-admission rule requires a new version frozen before execution. Exact quotation repair cannot change statistical fields. Frozen failures and raw sources remain immutable. Same-model checking is procedural separation, not independent expertise; abbreviated RoB drafts are not expert RoB2/GRADE.

## Required handoff

Save actual commands, source/contract/code/model pins, attempts, PIDs/exit states, source and request receipts, accepted/unresolved decisions, audit outputs and concrete next action. State whether the result is a source assessment, fixed-input sensitivity, complete declared quantitative analysis or complete review. A supported discrepancy can be a successful benchmark; unsupported data cannot. Do not count tests or rounded pooled agreement as scientific completion.
