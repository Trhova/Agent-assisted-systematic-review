# Executable bounded model continuation

Implemented `scripts/continue_model_requests.py` to remove the repeated manual recovery exposed by Alabed family and RoB backend failures. It consumes an immutable manifest, validates exact request/model/source/success-cache/code identities, imports successful work, finds identical later successful receipts, and produces a complete successor cache usable by the existing runner. Otherwise it performs at most one permitted adapter invocation, after cooldown, under a shared request lock and durable budget. Uncertain submissions remain blocked. Transport success never converts a negative scientific verdict into acceptance.

New backend options preserve historical default behavior while allowing recovery to request one adapter attempt. Receipts now record response-received time; optional ASR_MODEL_CACHE_ONLY prevents network execution during replay. Retry-After supports dates/delay-seconds and malformed values block resubmission. Complete operational contract and primary HTTP references are in `protocol/extensions/bounded_model_continuation_v1.md`.

The actual frozen command arrays are preserved in `family_launch.json` and `rob_launch.json`; manifests document all required fields. For a new execution freeze current Python with scripts.run_frozen.bundle, set that digest in the manifest, then launch with scripts.run_frozen.command. Use a fresh output, preserve the shared ledger, reconcile inactive original runners first, and pin any downstream non-Python assets. Completed validation outputs must not be overwritten or needlessly rerun.

Limits: the ledger protects cooperating continuation invocations sharing that ledger, not unrelated ordinary model_json runners. Provider-level idempotency is unavailable here, so unresolved timeout/submission states require evidence reconciliation. The CLI may retry transport internally. This is a usable manual/heartbeat entry point, not an automatically installed schedule or a replacement for scientific gates. No numerical/meta-analysis rerun was performed this cycle.
