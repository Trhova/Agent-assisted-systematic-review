# Comparing a published analysis with an independently specified method

A missing exact software invocation prevents an exact-method reproduction claim. It does not, by itself, prevent an agent-assisted, source-grounded comparison using a scientifically justified method specified before execution. This distinction follows the accepted release scope; it does not change the strict exact-reproduction qualifier or old failed qualifications.

Before freezing a comparison, establish the complete published contributor set and its actual population, arm, outcome and follow-up definitions from original sources. Declare any deliberate departure. A mixed outcome grouping must retain every original operational definition and its clinical limitations; it cannot be renamed a uniform endpoint. Do not trim inaccessible or unresolved contributors. A matching source quotation does not establish statistical compatibility, analyzed N or independence.

Specify the analysis method, assumptions, transformation and zero-event policy before model extraction. Keep the reference's unknown estimator explicitly unknown. Maintain separate evaluator-only reference artifacts and numerical tolerances. The scientific requests receive original reports and the frozen question, never published pooled answers or proposed reference cells.

Report at least four separate conclusions: primary-input completeness, source-verified reference inputs and mappings, numerical comparison under the prespecified method, and exact-method reproduction status. A demonstrated reference input discrepancy can be a useful benchmark finding even if the published estimator remains uncertain. Quantify its impact with an explicitly labelled evaluator-only calculation under the same chosen method; any remaining discrepancy stays unexplained. Numerical resemblance cannot identify the original estimator.

Cochrane Handbook [Chapter10](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-10), especially10.2,10.4.1 and10.10, supports considering the review question, binary method and clinical diversity before synthesis. Fixed-effect assumptions and heterogeneity must be stated; a pooled estimate is not proof of one universal treatment effect. This workflow is for a declared development comparison, not clinical decision support or prospective validation.

Example: `benchmarks/protocols/inhaled_escalation_v1.yaml` preserves all four contributors and the published hospitalization analysis's broader STOIC urgent-care composite, with14/28/30-day follow-up differences. Its outcome is distinct from the prior unresolved symptom-recovery analysis, which remains unchanged. Consult the current execution and verification receipts before claiming that any release gate passed.
