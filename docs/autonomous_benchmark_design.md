# Autonomous review benchmark design

The benchmark measures discovery, source accessibility, extraction and synthesis separately. Frozen protocols live in `benchmarks/protocols`; published answers and article identities live in `benchmarks/references`. The runner does not read reference files. Model prompts omit benchmark names, published pooled estimates and expected study counts. The separate `compare` command reads answers after execution. Model pretraining may include these papers; this design prevents direct prompt leakage but cannot establish that the underlying model has never seen a review.

Ma 2013 and Li 2016 were selected because they concern live microbiome interventions in metabolic disease, have accessible review articles, and contain relatively small outcome-specific sets. Their older primary reports are an intentional access feasibility test, not guaranteed open-access corpora. Ma's exact historical search date is absent; its submission date is explicitly used as a proxy. Neither benchmark changes the repository's original 2014–2024 protocol.

A current Europe PMC MED search is not an archived replay of PubMed, Embase and the other databases used by the authors. Search snapshots preserve raw responses, queries, retrieval date and bibliographic metadata. Indexed reviews are excluded deterministically; other records receive conservative title/abstract screening. Ambiguous records proceed to full-text review. Missing accessible reports remain unresolved, rather than being treated as ineligible.

Full-text acquisition uses Europe PMC JATS, PMC Cloud, the existing local corpus matched by PMID, indexed public links, DOI/repository metadata and bounded isolated web searches for exact primary-article URLs. If a purported public copy cannot be downloaded, one bounded alternative-source search excludes failed URLs. Acquisition does not bypass authentication. URLs, full texts, raw downloads and hashes are retained. Oversized conference collections undergo lossless segmentation and, where a verified PDF is available, a separate geometric reading-order projection. Discovered leads require separate bibliographic identity resolution and screening; segments are never pooled as independent studies.

Extraction requires reported arm means, SDs, analyzed sample sizes, units, timing, endpoint/change definition, trial identity and source quotations. Numeric availability is distinct from trial eligibility. Secondary reports can supply data for the same trial; they are not independent studies. A separate model call checks extracted values against source text. Exact quotations are checked deterministically. This is a consistency check, not independent human validation or a claim of error-free extraction. A separate source-backed trial-family stage verifies report relationships, with a bounded maximum of 64 pairs. Unknown relationships, conflicting identities and discordant duplicate comparisons remain unresolved; the system does not claim comprehensive linkage when that bound or source evidence is insufficient.

The analysis supports independent parallel comparisons only. It refuses repeated trial IDs and incompatible outcome, unit, measure or endpoint/change definitions. SMDs retain their source units but are pooled on a dimensionless scale. No median-to-mean conversion, SD imputation, change-score correlation assumption, shared-control splitting, crossover or cluster correction is applied automatically. A separately versioned opt-in extension for new protocols enumerates and independently verifies every original randomized arm before combining eligible disjoint groups. Neither frozen historical benchmark enables it.

MD variances are sums of arm mean variances. Hedges' correction and SMD variance follow the [RevMan statistical algorithms](https://documentation.cochrane.org/revman-kb/files/210600101/210600103/1/1654774257333/Statistical_methods_in_revman.pdf). Pooling uses inverse-variance fixed effects or DerSimonian–Laird random effects, normal 95% confidence intervals, Q, I² and leave-one-out sensitivity. Small-study uncertainty and contemporary alternatives such as REML/Hartung–Knapp are not hidden by calling this a universally preferred estimator; these methods were chosen for historical comparability.

The published Li article inconsistently labels its effects as SMD and weighted mean differences and attaches physical units to SMD. Its methods explicitly state SMD, which is the frozen primary comparison. A different analysis may be reported as a sensitivity analysis, never substituted post hoc to make the benchmark pass.

Successful execution requires no unresolved records/errors and enough validated independent effects. Numerical benchmark matching additionally requires the prespecified study count and point estimate/CI tolerance. When exact source-report IDs are available, their set is also checked. Report-level identity is distinguished from comprehensive trial-family equivalence. Incomplete runs may emit provisional estimates, but cannot pass the benchmark. Coverage failures, scientific differences and software failures are reported separately.

API payloads follow [OpenAI structured-output documentation](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses); the authenticated alternative uses [Codex non-interactive execution](https://learn.chatgpt.com/docs/non-interactive-mode). Numeric extraction CLI calls run outside the repository with user configuration ignored, shell and web disabled, and tool-use events rejected. The separate source finder permits audited web search for article URLs only; it receives no outcome values or benchmark targets. Calls have finite timeouts/retries and immutable request/response artifacts. A default CLI model is not a pinned model version; callers should supply `--model` for version-controlled comparisons.

PMC's legacy OA Web Service/FTP distribution was retired in August 2026. Retrieval now uses the [current PMC Cloud dataset](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/) and its [documented layout](https://pmc-oa-opendata.s3.amazonaws.com/README.txt). Data source: NIH NLM NCBI PubMed Central Article Datasets, accessed 2026-10-12. Local snapshots reflect their retrieval time and are not automatically kept current. PMC article licenses and metadata are retained with downloaded PDFs. No NLM endorsement is implied.

## Assisted acquisition and live implementation corrections

The first standalone passes used only indexed acquisition and had no accepted effects. During diagnosis, the coding agent searched primary trial titles on the web and supplied additional publicly reachable PDFs: Ma benchmark PMIDs 22013734, 21901256 and 23396737; Li benchmark PMIDs 23899653 and 26988693. The selected reports were known from the benchmark reference lists, although all had independently survived screening. This is **evaluator-assisted source acquisition**, not a blind autonomous discovery success. Per-source `source_discovery.json` records preserve URLs, identity checks and access failures; neither published pooled results nor forest-plot numbers were supplied to extraction. These local PDFs are not redistributed. A future clean benchmark must rerun source discovery without this assistance.

Source-grounded implementation corrections made during these runs include exact-quote formatting repair, preserving contextual caveats for verification rather than treating every caveat as automatic invalidity, and recognizing U/L, IU/L and UI/L as enzyme-activity labels for ALT/AST only. Original unit labels remain recorded. This does not equate general WHO international units with catalytic units; see the [IUPAC enzyme international-unit definition](https://goldbook.iupac.org/terms/view/I03114) and [NIST enzyme reference measurement report](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nbsspecialpublication260-83.pdf). Model verification must still establish support for every number and reject unresolved analyzed-denominator or SD/SE conflicts.

These are development benchmarks, with cached requests reused after corrections, not untouched held-out evaluations. Historical attempt outputs and code snapshots are preserved where available; early interim status files preceded attempt archiving and are not all recoverable. Future reruns archive prior status/extractions/synthesis before replacing the live view and remove stale synthesis/comparison files. A source gap cannot silently inherit an earlier pooled result.
