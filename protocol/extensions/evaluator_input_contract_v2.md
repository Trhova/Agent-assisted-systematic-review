# Evaluator input contract v2

This is an evaluation/reporting policy, not a new pooling or eligibility method. It preserves existing scientific inputs and historical comparator observations. It consumes a finished run with frozen status, protocol, accepted inputs, family decisions, synthesis and comparator. A separate pinned reference may supply binary cells with exact published source hash and locator. Reference material is evaluator-only.

Report numerical/semantic agreement, report coverage, explicit trial/arm/time mapping, observed cell comparisons, independently verified agreement, scoped reproduction, whole-review claims and prospective claims separately. Missing cells mean not assessed; manually transcribed matching cells are not independently verified. Traceability hashes are not evidence of transcription accuracy. Ambiguous repeated trial/report mappings fail closed. Missing/misaligned study identity, arm labels, timepoint or reference locator prevents verified agreement. Current mapping supports one outcome/comparison per independent trial only.

An independent-reference verification receipt must attest to the exact reference hash and mapping digest, name an independent reviewer and verification method, provide the evidence locator and affirm validity. The evaluator validates the receipt binding, not the reviewer's actual independence or scientific truth. That limitation is always reported. Without such a receipt, an observed disagreement is a disagreement in transcribed cells; verified input/contributor agreement remains unknown. Published target cells never replace primary inputs.

Scoped reproduction requires valid artifact replay, matching semantics/numerics, report coverage, complete mapping, independently verified reference cells, exact input agreement and the original comparator's completion gates. This v2 development contract never establishes whole-review reproduction or prospective validation. Those claims require a broader separately specified evaluation design. Original historical comparator outputs remain unchanged.

Standalone CLI writes a new output outside the source run and checks the entire source directory before/after. Optional benchmark-suite evaluation_contract enables the policy only when explicitly pinned; absent this opt-in historical behavior remains. For preserved evaluations use the standalone command: normal suite exports may otherwise write to their run directories. No model call is required.
