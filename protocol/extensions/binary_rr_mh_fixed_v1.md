# Binary RR, fixed Mantel–Haenszel v1

Specified before the Popp2021 development execution. Supports participant-level binary outcomes from independent, individually randomized parallel groups. Requires exact integer event counts and explicitly reported outcome analysis denominators. A trial's source-explicit ITT table is usable with its stated missing-outcome limitations; this does not authorize classifying missing participants as non-events. Rates, recurrent event totals, hazard ratios, adjusted estimates, cluster and crossover trials are unsupported. Event-count aggregation is permitted only for an explicit exhaustive mutually exclusive primary-source partition; retain component counts and source quotations, independently verify the partition, and deterministically verify its sum. Percentages are not converted to counts.

The method is the risk ratio with fixed Mantel–Haenszel weights; normal confidence interval on log RR with the Mantel–Haenszel variance. Individual effects are stored on log RR; pooled estimates and intervals are explicitly on the RR scale. Heterogeneity Q uses inverse sampling-variance weights about the MH log estimate. Fixed effect tau² is zero by model, not estimated. No automatic heterogeneity-driven switch to another estimator.

Zero-cell policy: add 0.5 to all four cells in a study containing a zero cell, retaining original and corrected counts. Studies with both arms zero events or both arms all events are retained in an explicit noninformative ledger and do not contribute to the relative-effect estimate. Require at least two informative independent studies. This conventional correction can be biased for rare outcomes or imbalanced groups and is not presented as an optimal rare-event method. The initial qualified primary set has no zero cells; zero handling is tested but not clinically validated by this case.

Method sources: [Cochrane's current analysis guidance, section 10.4](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-10), and the linked [Deeks/Higgins RevMan statistical algorithms](https://training.cochrane.org/handbook/current/statistical-methods-revman5), pp.2–3 and5–6, equations3–4 and MH heterogeneity. The retrieved linked PDF is dated August2010, not a newly authored2026 method. Raw PDF and SHA256 are preserved in the source qualification directory.

This extension does not change frozen continuous protocols or silently substitute RR for a trial-reported rate ratio. Fixed MH RR is selected here because it is the published review's explicit main mortality estimator; its separately reported random-effects sensitivity is outside v1 implementation scope. Model selection is frozen before execution, not chosen from observed heterogeneity.
