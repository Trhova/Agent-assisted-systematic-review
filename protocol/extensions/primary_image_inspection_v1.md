# Bounded primary-image inspection v1

Normal supplement augmentation builds a hash-checked document-order image queue from original raw DOCX/context/assets. External images are not fetched. Adjacent text is labelled as adjacency, not assigned as caption ownership. The queue is exposed in ordinary source metadata and outcome-availability continuation output.

Inspect at most one pending image per frozen invocation, selected by first document order, with two isolated image-backed calls (one proposal and one verification), one adapter attempt each. No automatic recovery. The manifest freezes all source files, selected identity, question, explicit model and code. Requests receive original pixels/context only, no review targets. Preserve actual image/submission/response receipts and visual wording; never fabricate verbatim text quotations, digitize graphs or infer N/dispersion.

Checked relevant, irrelevant, unreadable, unclear relevance and unverified outcomes are durable nonpending states. Any revisit needs a new justified contract; no endless automatic loop. Successor source metadata references the exact inspection receipt inside its own directory, bound to image/context identity/hash. Raw primary text/hash remain unchanged; observations do not become textual source quotes.

Numerical admission is always false under this policy, including when an inspector says numeric fields are visible. Quantitative use requires a separately supported outcome/design/evidence contract and full validation. Same-model procedural separation is not independent human expertise; correlated errors remain possible. Johnston's household allocation is not repaired by visual inspection.
