# Original table image input admission v1

This opt-in evidence policy reads explicitly printed event counts and outcome-specific analyzed denominators from a full original PDF page. It does not digitize graphs, reconstruct counts from percentages, substitute randomized header N, infer SD/ICC, or estimate missing inputs. Unknown values remain null and block admission. The frozen outcome contract specifies population, intervention/comparator, outcome and horizon. Only individual parallel binary participant counts are supported here; existing binary MH methods are unchanged.

A source-only first request receives original page pixels and exact primary methods context, never review targets or previous extracted cells. A separate request sees the same sources and first reading. Cells, denominators, arms, outcome, timepoint, population, individual parallel design, original identity and locator must each be supported. Any unclear axis blocks admission. Contextual limitations are retained. Both requests use the same explicitly pinned model; their separation is procedural and does not establish independent human expertise.

The consumer reconstructs requests, validates successful response/image receipts, re-renders original PDF pixels, validates source text/context/contract hashes and binds every output row field. Image observations remain labelled as visual readings, not fabricated source-text quotations. An exact methods quotation is required. Opt-in normal input validation can accept this evidence modality only with its entire original outcome contract; it cannot be transplanted to another outcome. This is input admission, not automatic trial eligibility, integrity clearance, family independence or permission to pool. Frozen old sources/protocols/results remain unchanged.

Current calibration: ORCHID original Table 2, original-report page 7 (provider collection page 14), all-cause all-location death at 28 days, hydroxychloroquine versus placebo, hospitalized adults. It tests a material denominator distinction in an already accessible PDF; it does not newly recover an inaccessible study. Source selection is post-hoc development context. No numerical synthesis is rerun and no reference-review results are supplied to model calls.
