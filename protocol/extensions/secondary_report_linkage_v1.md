# Secondary report linkage v1

Purpose: retain an editorial synopsis as a secondary report linked to an already retained original trial report. This is not an eligibility exclusion or an assertion that inaccessible secondary information is irrelevant.

Require successful publisher identity/source/quote replay, independently checked explicit synopsis attribution and original-report citation, a citation title matching the original search record, and the original record retained among independent inputs. Freeze source run hashes and role assessment before execution. Reject unclear roles, self-links, absent original records, changed evidence and mismatched citations. Preserve the access gap, secondary report and all original scientific decisions.

Methodological basis: Cochrane Handbook current Chapter4, sections4.6.1–4.6.2 and MECIRC42, https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04 (consulted14October2026). Collate reports by study and retain secondary reports for potentially valuable information. Publisher synopsis linkage does not establish shared randomized participants between separate trials. Counts must distinguish unresolved linked secondary reports from unresolved unlinked reports; the latter are not a count of proven missing studies.
